# Telegram-бот и Mini App ресторана

Клиент открывает меню кнопкой в Telegram: каталог с фото, корзина, оформление доставки или самовывоза и история заказов. Заказы приходят администратору в Telegram с кнопками статусов, клиент получает уведомления. В чате бота работает AI-помощник, который отвечает на вопросы по данным ресторана.

## Запуск

```bash
npm install        # установить библиотеки (один раз)
npm run setup      # создать таблицы, загрузить меню и собрать Mini App (один раз)
npm start          # запустить бота и Mini App
```

Остановить — `Ctrl+C` в окне терминала.

Telegram открывает Mini App только по адресу `https://`. Для работы на своём компьютере впишите в `.env` токен ngrok (`NGROK_AUTHTOKEN`) — при запуске бот сам откроет туннель и поставит кнопку «Меню» в чате.

## Настройки — файл `.env`

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_IDS` | Telegram ID администраторов через запятую (узнать: команда `/id` в боте) |
| `ORDERS_CHAT_ID` | необязательно: ID группы сотрудников для заказов |
| `DATABASE_URL` | строка подключения PostgreSQL (Neon) |
| `ANTHROPIC_API_KEY` | ключ Claude API для AI-помощника |
| `AI_MODEL`, `AI_EFFORT` | модель и глубина размышлений AI |
| `AI_QUESTIONS_PER_HOUR` | лимит вопросов AI от одного клиента в час |
| `WEBAPP_PORT` | порт веб-сервера Mini App (по умолчанию 3001) |
| `NGROK_AUTHTOKEN` | токен ngrok: https://dashboard.ngrok.com/get-started/your-authtoken |
| `NGROK_DOMAIN` | необязательно: постоянный домен ngrok, чтобы адрес не менялся |
| `MINI_APP_URL` | необязательно: свой https-адрес вместо ngrok |

## Данные ресторана — папка `restaurant/`

| Файл | Что внутри |
|---|---|
| `restaurant.yaml` | название, адрес, телефон, часы работы, доставка, оплата, частые вопросы для AI, блюдо для предложения в корзине |
| `menu.yaml` | категории и блюда: названия, описания, цены, фото, острота |
| `texts/ru.yaml`, `texts/uz.yaml` | тексты бота в чате и в сообщениях администратору |
| `images/` | свои фото блюд (в `menu.yaml`: `photo: "images/plov.jpg"`) |

Тексты внутри самого Mini App — в `miniapp/src/i18n.js`.

После изменений: `npm run check` — проверить файлы, затем перезапустить бота или нажать «🔄 Обновить данные из файлов» в `/admin`. Изменили `miniapp/src` — выполните `npm run app:build`.

Чтобы сделать бота для другого ресторана — скопируйте папку проекта, замените содержимое `restaurant/` и значения в `.env`.

## Администратору

- Новые заказы приходят в Telegram с кнопками статусов: Принять → Готовится → Передан курьеру / Готов к выдаче → Выполнен (или Отменить).
- `/admin` — активные заказы, статистика, стоп-лист, пауза приёма заказов, вопросы, на которые AI не нашёл ответа.
- `npm run db:studio` — просмотр базы данных в браузере.

## Для разработчика

- Бэкенд: Node.js 22.18+, grammY, Express, Prisma 7 + PostgreSQL, Claude API (`@anthropic-ai/sdk`), ngrok (`@ngrok/ngrok`).
- Mini App: React + Vite в папке `miniapp/`. `npm run app:dev` — режим разработки (запросы `/api` уходят на `localhost:3001`).
- `src/webapp` — веб-сервер Mini App: проверка подписи Telegram (`initData`) и API. `src/controllers`, `src/routes` — бот (приветствие, AI, админка). `src/models` — база, `src/services` — AI, уведомления, часы работы, ngrok.
- `npm test` — проверки логики, `npm run test:flow` — полный сценарий бота и Mini App на имитации Telegram (использует базу из `.env`, тестовые данные удаляет).
- Изменили `prisma/schema.prisma` — создайте миграцию: `npx prisma migrate dev --name <название>`.
