# Публикация проекта в интернете

Проект состоит из двух частей, и живут они на разных сайтах:

| Часть | Где | Что делает |
| --- | --- | --- |
| Меню (Mini App) | **Vercel** | То, что видит гость: меню, корзина, оформление заказа |
| Бот и сервер (backend) | **Render.com** | Отвечает в Telegram, принимает заказы, работает с базой |
| База данных | **Neon** (уже есть) | Хранит заказы, пользователей, меню |

Меню на Vercel само ничего не считает: все запросы вида `/api/...` оно
незаметно передаёт на Render. Поэтому имя сервиса на Render важно и должно
совпадать с адресом, записанным в файле `miniapp/vercel.json`.

---

## Часть 1. Backend на Render.com (делается вручную)

### Шаг 1. Регистрация

1. Откройте https://render.com и нажмите **Get Started** (или **Sign In**).
2. Выберите **GitHub** и войдите под аккаунтом `SarvarKilichov`.
3. Разрешите Render доступ к репозиториям: **Only select repositories** →
   выберите `baxt_restaurant_bot` → **Install**.

### Шаг 2. Создание сервиса

1. В панели Render нажмите **Add new** → **Web Service**.
2. В списке репозиториев найдите `baxt_restaurant_bot` и нажмите **Connect**.

### Шаг 3. Настройки сервиса

Заполните поля точно так:

| Поле | Значение |
| --- | --- |
| **Name** | `baxt-restaurant-bot` |
| **Language** / Runtime | `Node` |
| **Branch** | `main` |
| **Region** | `Frankfurt (EU Central)` |
| **Root Directory** | оставить пустым |
| **Build Command** | `npm install && npm run db:migrate` |
| **Start Command** | `npm start` |
| **Instance Type** | `Free` |

> ⚠️ Имя **Name** должно быть именно `baxt-restaurant-bot`. Если Render
> скажет, что имя занято, придумайте другое и сообщите его мне — я поправлю
> файл `miniapp/vercel.json` и заново опубликую меню.

### Шаг 4. Переменные окружения

Нажмите **Advanced** → **Add Environment Variable** и добавьте строки ниже.
Значения возьмите из файла `.env` на вашем компьютере (он не попадает на
GitHub, поэтому переносить значения нужно руками).

| Ключ (Key) | Значение (Value) |
| --- | --- |
| `BOT_TOKEN` | токен бота из `.env` |
| `DATABASE_URL` | строка подключения к базе из `.env` |
| `ADMIN_IDS` | ваш Telegram ID из `.env` (узнать заново: команда `/id` боту) |
| `MINI_APP_URL` | адрес меню на Vercel (я его пришлю) |
| `NODE_VERSION` | `22.18.0` |

Необязательные:

| Ключ | Значение |
| --- | --- |
| `ORDERS_CHAT_ID` | ID группы сотрудников, если она есть |
| `ANTHROPIC_API_KEY` | ключ Claude, когда появится (без него AI-помощник просто выключен) |

> Переменные `NGROK_AUTHTOKEN`, `NGROK_DOMAIN` и `WEBAPP_PORT` на Render
> **не нужны** — они только для запуска на своём компьютере.

### Шаг 5. Проверка доступности

Пролистайте страницу ниже, найдите **Health Check Path** и впишите:

```
/health
```

Затем нажмите **Deploy Web Service**.

### Шаг 6. Дождитесь запуска

Откроется страница с логами. Первый запуск занимает 3–5 минут. Дождитесь
строк:

```
==> Your service is live 🎉
✅ Бот @<имя_бота> запущен
```

Наверху страницы будет адрес сервиса, например
`https://baxt-restaurant-bot.onrender.com`. Откройте в браузере
`https://baxt-restaurant-bot.onrender.com/health` — должно появиться
`{"ok":true}`.

### Шаг 7. Чтобы бот не «засыпал»

На бесплатном тарифе Render усыпляет сервис после 15 минут тишины, и первый
заказ после паузы может прийти с задержкой до минуты. Два варианта:

**Вариант А (бесплатно).** Настройте внешний пинг:

1. Откройте https://cron-job.org и зарегистрируйтесь.
2. **Create cronjob** → в поле **URL** вставьте
   `https://baxt-restaurant-bot.onrender.com/health`
3. **Schedule**: `Every 10 minutes` → **Create**.

**Вариант Б (надёжнее, ~$7 в месяц).** В настройках сервиса на Render
смените **Instance Type** с `Free` на `Starter`.

## Часть 2. Меню на Vercel (делаю я)

Меню публикуется командой из папки `miniapp`. Адрес вида
`https://<имя-проекта>.vercel.app` нужно затем вписать на Render в
переменную `MINI_APP_URL` и перезапустить сервис (**Manual Deploy** →
**Deploy latest commit**).

## Проверка, что всё работает

1. Откройте бота в Telegram и отправьте `/start`.
2. Нажмите кнопку **Меню** внизу — должно открыться меню ресторана.
3. Добавьте блюдо в корзину и оформите заказ.
4. Заказ должен прийти в Telegram администратору (`ADMIN_IDS`).

## Если что-то не работает

| Что видно | Причина и решение |
| --- | --- |
| Бот не отвечает на `/start` | Смотрите логи на Render (**Logs**). Чаще всего неверный `BOT_TOKEN` или `DATABASE_URL` |
| Кнопки «Меню» нет | На Render не задан `MINI_APP_URL`, либо после его добавления не перезапущен сервис |
| Меню открывается, но пустое или «Ошибка сервера» | Имя сервиса на Render не совпадает с адресом в `miniapp/vercel.json` |
| «Откройте приложение заново из Telegram» | Меню открыто в обычном браузере — так и должно быть, открывайте из Telegram |
| Долгая загрузка после паузы | Сервис засыпал, см. Шаг 7 |

## Обновления в будущем

Render и GitHub связаны: после каждой отправки изменений на GitHub Render
пересобирает backend сам. Меню на Vercel я публикую отдельной командой.
